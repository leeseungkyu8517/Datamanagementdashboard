 전체 개발 순서                                                                                                                                                                                                                                                                                                                                                                                                                                                        
  Phase 1 — 데이터 기반 (지금 해야 할 것)                                                                                                                                                                                           
                  
  RLS 정책 설정 → 앱에서 데이터 읽기/쓰기가 되려면 필수

  -- Supabase SQL Editor에서 실행
  alter table companies enable row level security;
  create policy "allow all" on companies for all using (true);
  -- 나머지 테이블도 동일하게

  ---
  Phase 2 — 핵심 CRUD (이게 없으면 나머지가 의미없음)

  ① 거래처 관리 (companies)          ← 한국/일본/베트남 페이지
     └─ 담당자 관리 (company_managers)

  ② 영업인력 관리 (sales_personnel)   ← 각국 영업인력 페이지

  ③ 영업 이력 (sales_projects)        ← sales-history 페이지
     └─ 미팅 기록 (meeting_notes)

  이 세 개가 서로 연결되어 있어서 이 순서대로 만들어야 해요.
  거래처가 있어야 → 영업 프로젝트를 등록할 수 있고 → 프로젝트가 있어야 → 미팅 기록이 생겨요.

  ---
  Phase 3 — 부가 기능

  ④ 할일 관리 (tasks)                 ← my-tasks 페이지
  ⑤ 스케줄 관리 (schedules)           ← schedule 페이지

  ---
  Phase 4 — 집계/분석 (데이터 쌓인 후)

  ⑥ 영업 현황 대시보드 (이미 시작됨)
  ⑦ 기간별 예측 대시보드

  ---
  Phase 5 — Edge Functions (고급 기능)

  ⑧ 기업 정보 수집 + AI 요약 (company_data)
     └─ 크롤링 (company_data_crawling)

  이건 외부 API 호출이나 서버에서만 돌려야 할 로직이 생길 때 쓰면 돼요.
  지금 당장은 없어도 됩니다.
